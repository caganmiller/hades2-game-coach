# Using Game Coach

## Start a session

1. Open `GameCoach.exe`; it loads the configured local model automatically. Check **Ready** in Settings.
2. Select your microphone/display and choose an optional build route in **Sandbox → Pick your build**. Routes use recorded unlocks; load your game save before relying on this list.
3. Press **Start coaching**. The microphone and watcher start together, and the app minimizes. Bring Hades II to the foreground.
4. Say **“coach”**, wait for the rising tone, then ask. `Ctrl+Alt+L` starts a voice question without the wake phrase. Typed questions are available on the Coach page.
5. Say **“thanks”** to silence the current spoken response without ending the run. Say **“coach”** again to interrupt and ask something new. **Pause coaching** stops both microphone listening and watching and preserves memory.

## Useful things to say

- “I'm starting the run. Here's my setup.” Start a setup review and show equipped screens for a few seconds each; available options are not automatically treated as equipped.
- “Compare these with my current build.” Ask about the actual offered tradeoffs, including rarity, costs, and replacement losses.
- “I chose [boon name].” Explicit choices are recorded without asking you to repeat a confirmation.
- “What was the last boon I took?” The answer uses recent saved/confirmed evidence; an unsaved choice may still be pending.
- “What's missing from this build?” Check the next useful synergy, resource, or defensive gap.
- “Explain the boss tips.” Expand the introduction card on demand. Fast combat narration is not the primary boss feature.

## Read the guidance

1. **Boon and keepsake cards** compare visible choices against the saved build. A highlighted recommendation is not evidence that you selected it.
2. **Build markers** point to recognized offers or door rewards that support your selected route. Uncertain doors may get no marker.
3. **Boss cards** appear during recognized opening dialogue. They should disappear when dialogue ends; they are not attack-by-attack predictions.
4. **Current build** shows saved Boons, Equipment, and Arcana. Use **Refresh checkpoint** if the game has just saved. Hover or select an item for retained details.

## Explore and share

1. **Sandbox** contains build selection, a run briefing, checkpoint comparison, and review tools. Community routes are suggestions, filtered by known unlocks and adapted as evidence changes.
2. **Activity** shows local/cloud request counts, latency, outcomes, and reported usage. It does not replace your OpenAI billing dashboard or measure all GPU power consumption.
3. **Run history** groups completed and failed attempts. Synergies explain connected components; the loadout's **All** view is ordered **Boons → Equipment → Arcana**. Filters show just one group.
4. **Full build · HTML** is an interactive standalone file with retained item details. **Summary · PDF** is the shorter printable recap. Share can copy text or a PNG, or make a ZIP with HTML, PDF, PNG, and text. No automatic upload or public link is created.

Run greetings and congratulations are optional in Settings and can use cloud speech. Review any exported screenshot or run details before sending them to friends. Closing the app stops an engine it launched; it leaves an externally owned engine alone.
